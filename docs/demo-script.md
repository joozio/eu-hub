# 6-Minute Demo Script

## Goal
Show EU Hub as a trustworthy, personalized EU intelligence product with visible live provenance and a memorable AI moment.

## Flow
1. **Landing/Profile (45s)**
   - Set country + age.
   - Open profile and pick 2-3 priority themes.
   - Explain: personalization stays local.

2. **Dashboard (90s)**
   - Show live source status panel.
   - Highlight key stats and top news with source/freshness labels.
   - Click **My EU Impact Brief** and show generated opportunities/risks/action.

3. **Feed (75s)**
   - Show relevance-ranked cards and “why relevant” chips.
   - Point at provenance/freshness.
   - Open one official source link.

4. **Stats + Rankings (75s)**
   - Show country vs EU stats and priority-driven highlights.
   - Show ranking coverage and Eurostat freshness badge.

5. **EU vs World + Ask (60s)**
   - Show curated comparison with legal-source links.
   - Ask one policy question in natural language.

6. **Resilience fallback (35s)**
   - Append `?demo=1` and reload one page.
   - Show snapshot fallback and unchanged UX continuity.

## Closing line
“EU Hub turns public EU complexity into trusted, personal action in seconds.”
